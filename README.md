# Ismail Hossain's portfolio

Personal site built with Next.js. Run locally with `pnpm install` and `pnpm dev`.

To receive messages from the contact form, set `SMTP_HOST`, `SMTP_USER`, `SMTP_PASSWORD`, and `CONTACT_EMAIL` in `.env.local`. `SMTP_PORT` defaults to 587; `SMTP_FROM` defaults to `SMTP_USER`.
